## 🔄 核心处理流程

```
上传文件 → PaddleOCR API 异步识别 → 轮询结果 → 提取结构化数据 → 生成报告
```

### 详细流程：
1. **文件上传**：通过 `/api/upload` 上传图片，生成 `file_id`
2. **任务提交**：调用 `/api/submit/{file_id}` 提交到百度 PaddleOCR API，获取 `job_id`
3. **轮询结果**：通过 `/api/poll/{task_id}` 每5秒轮询任务状态
4. **结果提取**：任务完成后，从 JSON/Markdown 结果中提取结构化数据
5. **报告生成**：生成 Markdown 报告并保存到 `output/` 目录
